# Calorie Tracker

Premier projet Cursor — prise en main de l’outil.

Objectif : remplacer MyFitnessPal par une app **sans pubs**, **lean**, **minimaliste**.
Pour l’instant : calories + macros, calendrier coloré, repas / en-cas, Open Food Facts, settings Mifflin–St Jeor.

## Stack

Next.js · IndexedDB (Dexie) · Vercel · PWA

## Local

```bash
npm install
npm run dev
```

## Notes

Données stockées sur l’appareil. Export JSON dans les réglages.
